# 零食售卖商城 MVP 方案（分布式微服务 + 双前端）
基于**最小可用产品（MVP）** 设计原则，只保留核心业务流程，砍掉所有非必要功能，快速上线、验证业务；技术栈统一使用 **SpringBoot 3 + SpringCloud + Vue3**，兼顾轻量化与扩展性。

整体架构分为三大分系统：
1. **分布式微服务后端**（核心服务层，统一支撑双前端）
2. **商品售卖端**（C端消费者，购物核心）
3. **零食管理后台**（B端运营人员，管理核心）

---

## 一、分布式微服务后端（MVP 极简版）
### 核心定位
统一为**消费者端 + 管理后台**提供接口服务，采用**轻量级微服务架构**，不做过度拆分，保证可运行、可扩展。

### 1. 核心技术栈选型
| 技术分类 | 选型 | 选型理由（MVP 适配） |
|----------|------|----------------------|
| 基础框架 | SpringBoot | 自动配置、快速开发 |
| 微服务生态 | Spring Cloud | 服务注册/发现、网关、配置统一管理 |
| 服务注册/配置 | Nacos | 一站式注册中心+配置中心，部署简单 |
| 服务网关 | Spring Cloud Gateway | 统一路由、跨域、接口限流 |
| 接口通信 | OpenFeign | 微服务间极简调用 |
| 数据库 | MySQL | 关系型数据存储，通用稳定 |
| 缓存 | Redis | 商品缓存、购物车、登录状态 |
| ORM | MyBatis-Plus | 简化CRUD，提升开发效率 |
| 安全认证 | Spring Security + JWT | 无状态登录，支持多端鉴权 |
| 接口文档 | SpringDoc OpenAPI (Knife4j) | 适配SpringBoot3，自动生成接口文档 |
| 构建工具 | Maven | 项目依赖管理 |
| 容器 | Docker | 一键部署，环境统一 |

### 2. 微服务拆分（MVP 最小化）
仅拆分**4个核心微服务**，不做冗余拆分：
1. **网关服务**（api-gateway）
2. **用户服务**（user-service）
3. **商品服务**（product-service）
4. **订单服务**（order-service）

### 3. 核心功能模块（MVP 必选）
#### （1）网关服务
- 统一接口路由（分发到各微服务）
- 全局跨域处理
- JWT 令牌校验
- 接口访问日志

#### （2）用户服务
- 用户注册（手机号+验证码）
- 用户登录（JWT 签发）
- 用户基础信息管理（昵称、头像、地址）
- 收货地址增删改查
- 管理员登录鉴权

#### （3）商品服务
- 商品分类管理（一级分类）
- 商品CRUD（名称、封面、价格、库存、详情）
- 商品上下架
- 商品列表+分页+搜索
- 商品详情页
- 商品库存扣减/回滚

#### （4）订单服务
- 创建订单（关联商品+地址）
- 订单列表（用户/管理员查看）
- 订单详情页
- 订单状态流转（待支付 → 已完成）
- 订单删除/取消
- 订单支付模拟（MVP 无真实支付，仅状态变更）

#### 公共基础功能
- 全局异常处理
- 统一响应结果封装
- 数据分页工具
- 接口限流（MVP 无真实支付，仅模拟）

公共基础功能统一封闭在common 模块中，其他服务引用即可。

## 二、商品售卖端（C端消费者）
### 核心定位
面向普通用户，**只保留购物核心流程**：浏览商品 → 加入购物车 → 下单 → 查看订单，极简交互。

### 1. 核心技术栈选型
| 技术分类 | 选型 |
|----------|------|
| 框架 | Vue 3 + Vite |
| 开发语言 | TypeScript（可选精简版） |
| UI 组件库 | Element Plus |
| 状态管理 | Pinia |
| 路由 | Vue Router 4 |
| 网络请求 | Axios |
| 样式 | Less / CSS3 |
| 适配 | 移动端响应式 |

### 2. 核心功能模块（MVP 必选）
#### （1）用户模块
- 手机号验证码登录/注册
- 个人中心
- 收货地址管理
- 退出登录

#### （2）商品模块
- 首页商品推荐
- 商品分类浏览（一级分类）
- 商品搜索（名称/分类）
- 商品列表（分页）
- 商品详情页
- 商品收藏（可选极简）

#### （3）购物车模块
- 加入购物车
- 购物车列表
- 修改数量/删除商品
- 购物车结算

#### （4）订单模块
- 确认订单（选择地址+商品）
- 提交订单
- 订单列表（全部/待支付）
- 订单详情页
- 模拟支付

#### （5）公共模块
- 404 页面
- 加载状态/空状态
- 全局请求拦截（自动携带Token）

## 三、零食售卖管理后台（B端运营）
### 核心定位
面向运营人员，**只保留商品、订单、用户基础管理**，满足日常上架、发货、查看数据即可。

### 1. 核心技术栈选型
与售卖端完全统一，降低学习/维护成本：
| 技术分类 | 选型 |
|----------|------|
| 框架 | Vue 3 + Vite |
| 开发语言 | TypeScript |
| UI 组件库 | Element Plus |
| 状态管理 | Pinia |
| 路由 | Vue Router 4 |
| 网络请求 | Axios |
| 样式 | Less |
| 构建 | 打包部署 |

### 2. 核心功能模块（MVP 必选）
#### （1）登录认证
- 管理员账号密码登录
- 权限控制（仅管理员可访问）

#### （2）商品管理
- 商品列表（分页/搜索）
- 新增商品
- 编辑商品
- 上下架商品
- 删除商品
- 商品分类管理（一级分类）

#### （3）订单管理
- 全部订单列表
- 订单筛选（状态/时间）
- 订单详情页
- 订单状态修改（待支付 → 已完成）
- 订单导出（可选极简）

#### （4）用户管理
- 用户列表查看
- 用户详情页
- 禁用/启用用户（可选）

#### （5）控制台（数据概览）
- 商品总数
- 订单总数
- 今日订单数
- 用户总数

#### （6）系统设置
- 修改管理员密码
- 退出登录
